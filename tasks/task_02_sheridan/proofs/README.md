# Formal Proof Records

This directory will index admitted Task 2 proofs and their generated evidence. It does not contain
draft executable Python because Task 2 has not crossed the formal admission boundary.

Each admitted theorem must record:

- stable claim ID and emitted label;
- final formula and digest;
- source locator and mapping classification;
- direct proof steps and inferred substitutions;
- definition expansions;
- local axiom invocations;
- imported FOL dependencies;
- direct and transitive closure;
- proof mode: `direct`, `extensional`, or `ex_falso`;
- verifier result and evidence digest.

Generated proof traces belong under `artifacts/task_02/` and are never proof inputs.
