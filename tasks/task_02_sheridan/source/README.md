# Source Evidence

This directory will contain immutable source records for the formalization.

Before proof implementation begins:

1. retrieve the exact published and arXiv sources used by the project;
2. record canonical URLs, byte lengths, retrieval time, and SHA-256 digests;
3. compare the formal statements in Sections 2–6;
4. select the formalization basis and locator convention;
5. update every claim-ledger entry with a precise source location.

The current lock is deliberately incomplete. A placeholder digest is a blocking state, not a
source lock.
