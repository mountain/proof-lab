# Certificates

This directory will index independently checkable research certificates.

Possible certificate classes include:

- canonical finite-model witnesses;
- counterexamples to candidate invariants;
- proof-producing solver certificates for bounded instances;
- formal verifier artifacts for admitted lemmas or metatheorems.

Each certificate record must identify its statement, semantic level, producer, independent
checker, dependency and assumption closure, byte hash, and verification result. Solver logs without
an independently replayable check are evidence, not certificates.
