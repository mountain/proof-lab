# Conjectures

This directory will contain the append-only conjecture ledger.

Every candidate, including the Toggle invariant and finite-cycle bridge, must record:

- a stable identifier and normalized statement;
- the exact assumptions and semantic level;
- the experiment or argument that motivated it;
- attempted counterexamples and search bounds;
- dependencies on earlier conjectures;
- status such as proposed, refuted, restricted, or formally certified;
- links to witnesses, proof candidates, and decision records.

A frequently observed pattern is not a theorem. Refuted conjectures remain in the ledger so later
reports expose the complete research path.
